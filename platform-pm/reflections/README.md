# 每周复盘

每周约 30 分钟，选一件真实事件复盘；每月向产品、工程或业务 counterpart 收集一次具体反馈。当前尚未记录已完成复盘。

建议文件名：`YYYY-MM-DD-weekly-review.md`，使用实际复盘日期。

## 复盘模板

```text
日期 / 本周重点能力：
关联的匿名化案例：
实际场景：
我采取的行动及依据：
产生的结果：
Stakeholder 反馈：
遗漏或不足：
下次改变的一个行为：
证据索引或匿名化摘要：
```

月度反馈问题：“这次信息是否足够让你做决定？缺少什么？”

在第 30、60、90 天结合证据更新[路线图中的能力自评与实践进度](../roadmap.md)。区分个人行为和多团队共同影响的业务结果。
