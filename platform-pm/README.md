# 集团 AI 平台 PM：岗位能力学习导航

面向偏 IT 交付、负责 stakeholder 协调及依赖风险管理的项目经理，通过实际工作提升 backlog 治理、交付透明度、onboarding 和 adoption 能力。

## 学习入口

- [90 天能力发展路线图](./roadmap.md)：能力优先级、30/60/90 天安排、工作约定、度量、能力自评和实践进度。
- [WoW 模板](./templates/README.md)：需求入口、路线图与交付关联、接入就绪和决策记录。
- [匿名化案例与练习](./practice/README.md)：记录试点背景、行动和验证结果。
- [每周复盘](./reflections/README.md)：记录刻意练习、反馈与下次行动。

## 建议使用顺序

1. 阅读路线图，完成能力初评，选择一个接入用例。
2. 选用模板，先试行四周，记录事实和基线。
3. 将匿名化实践写入 practice，每周在 reflections 复盘。
4. 按路线图完成 30、60、90 天回顾，更新进度和成长证据。

文件建立不代表学习或实践已完成；完成记录以实际证据为准。内部项目资料保留在机构认可的系统，个人仓库存放通用模板和匿名化或合成案例。
