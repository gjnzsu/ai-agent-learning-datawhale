# 模板 A：需求入口与 backlog

```text
需求 ID / 名称：
提出部门 / 业务负责人：
目标用户及用例：
当前问题及证据：
预期结果 / 衡量方式：
关联平台能力 / 路线图目标：
期望日期 / 日期原因 / 未按期完成的影响：
最低可用范围 / 验收条件：
数据、安全及治理依赖：
产品负责人：
工程初步判断：工作量 / 容量 / 依赖 / 不确定性
状态 / 优先级及理由：
决策记录 / 下次评审日期：
```

状态建议：待澄清 → 待排序 → 已纳入交付计划 → 执行中 → 验证中 → 已完成；另设暂停和不采纳。阻塞单独标记原因、负责人及开始日期。

提交时先说明问题和负责人，近期交付项再补齐详细范围、依赖和验收条件。定期合并重复项、清理失效项。
