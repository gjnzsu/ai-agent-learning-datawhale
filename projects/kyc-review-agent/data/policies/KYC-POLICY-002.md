# 企业客户 KYC 材料要求（合成制度）

- 文档编号：`KYC-POLICY-002`
- 版本：`2.0`
- 生效日期：`2026-01-01`
- 分类：`synthetic-public`

## corporate-required-documents

企业客户应提交公司注册证明、法定代表人身份证明、最终受益人声明和有效地址证明。

## document-validity

地址证明自签发日起 90 天内有效。无法取得签发日期时，应交由 Auditor 人工确认。

## cross-document-consistency

不同材料中的公司注册号应保持一致。发现不一致时只能记录冲突并转交 Auditor，
Agent 不得自行批准或拒绝客户。

本文件仅用于学习 PoC，不代表任何真实银行或监管机构的制度。
